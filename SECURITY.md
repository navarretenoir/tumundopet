# Seguridad / Security

**Español.** Si encuentras una vulnerabilidad, repórtala de forma privada por la función *Private vulnerability reporting* de GitHub
(pestaña Security) o abre una incidencia en GitLab marcada como confidencial. Responderé lo antes posible. No hay servidores propios ni
cuentas: la app sólo se conecta a las fuentes de datos públicas indicadas en el README.

**English.** Please report vulnerabilities privately via GitHub's *Private vulnerability reporting* (Security tab) or a confidential
GitLab issue. The app runs no servers of its own and has no accounts; it only connects to the public data sources listed in the README.
