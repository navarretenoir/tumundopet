# Contribuir / Contributing

Las incidencias y *pull requests* son bienvenidos (español o inglés). Antes de enviar cambios, ejecuta las pruebas del repositorio
(`tests/` o el flujo de CI) y mantén el estilo del código existente. Los cambios generados con IA deben declararse en la descripción.
Issues and pull requests are welcome (Spanish or English). Run the tests before submitting, keep the existing code style, and
disclose AI-generated changes in the description.
