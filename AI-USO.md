# Uso de IA generativa / Generative AI disclosure

**Español.** Este proyecto fue desarrollado por **Javiera Navarrete** con **asistencia sustancial de IA generativa**:
el código, las recetas de empaquetado, la documentación y las capturas de pantalla se escribieron con *Claude Code*
(modelos Claude de Anthropic) siguiendo las instrucciones, el diseño y las decisiones de la autora, quien probó la aplicación
en dispositivos reales. Las tipografías, bibliotecas y datos de terceros se listan en `THIRD-PARTY.md`.
La IA no tuvo acceso a datos personales de usuarios: la aplicación no recopila ninguno.
Si una tienda o proyecto no admite software desarrollado con IA, este proyecto no debe enviarse a ella.

**English.** This project was developed by **Javiera Navarrete** with **substantial generative-AI assistance**: the code,
packaging recipes, documentation and screenshots were written with *Claude Code* (Anthropic's Claude models) following the
author's instructions, design and decisions; the author tested the app on real devices. Third-party fonts, libraries and data
are listed in `THIRD-PARTY.md`. The AI never had access to users' personal data: the app collects none.
If a store or project does not accept AI-assisted software, this project should not be submitted to it.
